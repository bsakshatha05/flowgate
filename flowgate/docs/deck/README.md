# Deck sources

The live deck is https://claude.ai/artifact/4cTm2bF8KoYtxJXWrvUnrL (a Slides artifact in the original owner's claude.ai account; ask them to share it with you or export a PPTX/PDF).

This folder is a backup of its content: `deck.json` (slide order, title, fonts), `deck.css` (shared styles) and one HTML file per slide in `slides/`. Speaker notes are the `<aside>` at the end of each slide. Images are stored in the artifact itself; the same screenshots are in `../screenshots/`.
