THE SOLUTION

FlowGate: six fixes in one system

01

Staggered slots

Each department and year gets a 10-minute entry and exit window, built from the timetable.

02

Parking pre-booking

Book before leaving home. The app picks the least crowded zone and its nearest gate.

03

QR gate pass

Guards scan a QR in a second. Entry, exit and slot timing are logged automatically.

04

Carpool matching

Students from the same area share rides. Drivers earn the priority parking zone.

05

Live control room

Gate cameras count vehicles with YOLOv8. Alerts flag queues and crowding.

06

Safe crossing windows

Security holds vehicles for two minutes so students can cross the gate safely.

Six features, each mapped to a pain point. Slots fix the delays. Pre-booking and gate assignment fix the circling and uneven parking. QR passes make the gate fast. Carpools take vehicles off the road. The control room and crossing windows handle safety.
