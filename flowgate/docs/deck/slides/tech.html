HOW IT’S BUILT

Runs on one laptop, today

LayerWhat we usedWhy
ServerNode.js, no packages for the coreOne command to start, works offline
DatabaseSQLite, built into NodeA single file, easy to back up
Live updatesServer-Sent EventsDashboards update with no refresh
Web appsHTML, CSS, JavaScript, Chart.jsWorks in any phone browser
QR passesqrcode-generator, jsQRScan by camera, code or one tap
Vehicle countingYOLOv8 + ByteTrack (Python)Uses existing CCTV feeds
Slots, forecast, simulationOur own models in JavaScriptSeeded, so results repeat exactly
Copilot (optional)Claude API, offline fallbackPlain-English answers, aggregates only
The core runs locally with one command: no cloud account, no install step, no Wi-Fi needed. The copilot can use Claude when a key and internet are available and falls back to offline rules otherwise. The camera counter is a separate Python script that posts counts to the same API, so any CCTV feed can plug in.
